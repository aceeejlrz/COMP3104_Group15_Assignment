COMP 2156 - DevOps Course
=========================

Course Overview:
This course introduces the principles and practices of DevOps, which
combines software development (Dev) and IT operations (Ops) to deliver
software faster and more reliably.

Topics Covered:
- Version control with Git and GitHub
- Branching strategies and Pull Requests
- Continuous Integration and Continuous Delivery (CI/CD)
- Automation using GitHub Actions
- Containers and Docker
- Monitoring and feedback in production

Learning Outcomes:
By the end of the course, students will be able to collaborate on a
shared repository, manage branches and merges, build automated CI/CD
pipelines, and explain how DevOps improves team productivity.

Group Assignment:
In this assignment, our group practices real DevOps workflows: each
member works on their own branch, makes commits, opens Pull Requests,
and the team reviews and merges changes into the main branch with a
CI pipeline running on GitHub Actions.
